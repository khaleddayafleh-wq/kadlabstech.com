KADlabs website

  index.html                      -> https://kadlabstech.com/
  pebblefall/privacy/index.html   -> https://kadlabstech.com/pebblefall/privacy/   (the privacy policy URL for Play Console)
  assets/                         -> images and the site icon

To put it online: upload this whole folder, as it is, to your host (for example Cloudflare Pages), then connect kadlabstech.com to it.
The site shows support@kadlabstech.com: set that address up (iCloud+ > Custom Email Domain) before launch.
